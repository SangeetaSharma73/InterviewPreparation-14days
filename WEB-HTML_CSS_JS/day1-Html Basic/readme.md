# Html basics

1. what is html and why it is used?

**Definition**

- Html (Hyper text markup language) is the standard markup language used to
  structure content on the web.
- It defines what content exists on a webpage and how it is organized, not how it looks.
- Html uses tags to describe elements like headings , paragraphs ,images , links , forms etc.

**✅ Why is HTML used?**

1. create structure of the webpage.
2. Define content hierarchy (heading,section , articles)
3. Enable browser rendering.
4. Work with css(styling) and javascript (behavior).
5. Provide seo and accessibility support.

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My Website</title>
  </head>
  <body>
    <h1>Welcome</h1>
    <p>This is my website.</p>
  </body>
</html>
```

- 📌 Without HTML, the browser has nothing to display.
